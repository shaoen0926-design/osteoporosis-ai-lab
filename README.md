# 骨鬆 AI 實作室｜醫療精華版

獨立的醫療人員AI實作輔助工具。情境為製作病人與家屬使用的骨質疏鬆衛教簡報，11題，操作時間估計49分鐘，實際另受生成等待、登入與講解時間影響。

1. 破冰①｜一句話寫衛教
2. 破冰②｜畫水豚醫療人員
3. 破冰③｜做骨鬆衛教重點卡
4. 提示詞①｜規劃簡報大綱
5. 提示詞②｜產出簡報內文
6. 繪圖①｜畫一張簡報封面
7. 繪圖②｜資訊圖表做結尾頁
8. AI 簡報｜直接產出 PPT
9. NotebookLM｜客製簡報風格
10. 圖片簡報｜把單頁內容畫成投影片
11. 互動網頁｜骨鬆衛教小測驗

每題提供主提示詞、複製按鈕、工具連結及完成目標，不設追問或加碼練習。所需共用來源自動包含於文字類提示詞；NotebookLM另提供來源複製按鈕。單次顯示一題，完成紀錄只存於目前瀏覽器。

開啟index.html，或在本資料夾執行 `python3 -m http.server 8769 --bind 127.0.0.1`。

原有東京版與嘉義醫院版未變更。此版本儲存於骨質疏鬆，網站：https://shaoen0926-design.github.io/osteoporosis-ai-lab/

骨鬆衛教六頁素材.txt內附國健署與NIAMS來源，為教學草稿，實際對外使用前請由醫療人員審閱。工具功能及可下載格式依帳號而異。
